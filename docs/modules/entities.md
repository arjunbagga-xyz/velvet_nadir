# Entities & Data Models (`entities.py`)

## Overview
Defines core data structures for identities, operators, sessions, and device handles across Velvet Nadir.

## Schemas
- `User`: Identity details, biometric keys, role allocations.
- `Session`: Active multimodal session tokens and conversation state.
- `DeviceEntity`: Lightweight representation of mesh node attributes for UI serialization.
- `Agent`: Subagent configurations, tool capabilities, and permissions.
