# Operational Skills (`skills/kill_agent.py`, `skills/firmware_ops.py`)

## Overview
Administrative and operational skills for cluster health, emergency shutdown, and firmware management.

## Skills
- `kill_agent`: Immediately halts runaway subagents or background tasks and cleans up leased resources.
- `firmware_ops`: Coordinates OTA firmware updates, checksum verification, and rollback logic for embedded mesh devices.
